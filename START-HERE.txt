1. IMAGE BAUEN

   Name: medialab:0.4.0
   Methode: Web editor
   Inhalt aus Dockerfile.portainer einfuegen.
   Ueber Select files medialab-0.4.0-build.tar.gz hinzufuegen.
   Build the image anklicken.

2. STACK AKTUALISIEREN
   Portainer -> Stacks -> mediaingest -> Editor
   Image-Zeile:

   image: medialab:0.4.0

   Diese Werte beibehalten/setzen:
   PUID=1026
   PGID=100
   WEB_PORT=8099
   TMDB_CREDENTIALS_FILE=
   DRY_RUN=true
   FFPROBE_ENABLED=true
   FFPROBE_TIMEOUT_SECONDS=90
   LIBRARY_PROBE_CONCURRENCY=2
   LIBRARY_PROBE_AUTO_START=false

   Update the stack anklicken.
   Pull latest image NICHT aktivieren; das Image ist lokal gebaut.
